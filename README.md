# ⚖️ CourtSimVR

**A VR Courtroom Simulation | Built with Unity & C#**

---

### 📌 About the Project

CourtSimVR is an immersive Virtual Reality courtroom simulation that brings a realistic legal environment into VR. The project combines interactive courtroom experiences with AI-powered communication to create an engaging simulation.

### ✨ Features

- Immersive VR courtroom environment
- Interactive VR Main Menu
- Smooth UI interactions and navigation
- In-game settings and volume controls
- AI-powered Judge
- Voice-based interaction with the Judge
- Real-time spoken responses

### 🛠️ Technologies Used

- **Engine:** Unity 6
- **Language:** C#
- **VR Framework:** XR Interaction Toolkit
- **Platform:** Meta Quest / Android VR
- **AI Integration:** AI-powered voice interaction
